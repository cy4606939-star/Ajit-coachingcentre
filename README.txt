AJIT COACHING CENTRE WEBSITE
============================

FILES
- index.html  : page structure and content
- style.css   : layout, colours, responsive design
- script.js   : mobile navigation, enquiry form, demo helper chat

HOW TO OPEN ON WINDOWS 11
1. Extract this ZIP file into a folder such as Desktop\AjitCoachingCentre.
2. Open that folder.
3. Double-click index.html. It should open in your browser.
4. To edit the website, open the folder in VS Code and edit index.html, style.css, or script.js.
5. Save your edits and refresh the browser.

IMPORTANT
- No Node.js, npm, or build tools are required.
- The enquiry form opens WhatsApp with a prepared message. It does not send automatically.
- The chat widget is a local FAQ demo, NOT a live AI assistant. A secure real AI connection requires a hosted backend/serverless function; do not put a private API key in browser JavaScript.
- The phone number and address are editable placeholders based on details previously provided. Confirm them before publishing.
- Images and Google Fonts are loaded from external services, so an internet connection is needed for those assets. The page layout itself is local.
- Before publishing, replace any details, images, course availability, and contact information that are not accurate for your centre.
- To publish free, you can use GitHub Pages or Netlify Drop after checking their current setup requirements.
